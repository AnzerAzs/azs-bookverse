## 📝 UPLOAD & MANAGE YOUR CONTENT

### **Where to Upload Books:**

#### **1. Using Admin Panel (Built-in)**

✅ Click ⚙️ **Admin** button in navbar
✅ Fill in:
- **Category Name** (e.g., "Science")
- **Image URL** (e.g., from Unsplash)
- **Google Drive Link** (folder link)
✅ Click **Add Category**
✅ Done! Category appears instantly

---

#### **2. Create Google Drive Folder for Each Category**

1. Go to **Google Drive**
2. Create new folder: "Quranic Technologies"
3. Right-click → **Share**
4. Copy sharing link
5. Go to Admin Panel
6. Paste link in Google Drive field
7. Users can access books from there!

**Google Drive Folder Link Format:**
```
https://drive.google.com/drive/folders/1xXxXxXxXxXxXxXxXxXxXxXxXx
```

---

#### **3. Get Image URLs**

Use **free image sites**:

**Unsplash** (Free high-quality images)
```
https://unsplash.com/
- Search for image
- Click image
- Copy URL from address bar
```

**Pexels** (Free stock photos)
```
https://www.pexels.com/
- Search
- Right-click image
- Copy image URL
```

**Pixabay** (Free royalty-free)
```
https://pixabay.com/
- Search
- Download or copy URL
```

## 🔑 IMPORTANT: Create Google Drive Folders

### **Step-by-Step:**

1. **Go to Google Drive:** https://drive.google.com

2. **Create folder:**
   - Right-click in Drive
   - Click "New Folder"
   - Name: "Quranic Technologies"
   - Click Create

3. **Upload books to folder:**
   - Open folder
   - Click "New"
   - Upload files → Select your PDFs/books
   - Wait for upload

4. **Share folder:**
   - Right-click folder
   - Click "Share"
   - Change to "Anyone with the link"
   - Copy link

5. **Get shareable link:**
   ```
   https://drive.google.com/drive/folders/1xXxXxXxXxXxXxXxXxXxXx
   ```

6. **Add to your site:**
   - Click Admin ⚙️
   - Paste this link
   - Submit!
